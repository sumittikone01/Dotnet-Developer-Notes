# SUBQUERY OPERATORS

### 1. ALL :

- *ALL* operator compares a value against all values returned by a subquery.
- It returns *TRUE* only if **all** values in the subquery satisfy the condition.
- Commonly used with comparison operators like  `=`, `!=`, `<`, `>`, `<=`, `>=`.

<aside>
💡

- If ‘All’ and ‘ANY’ IS NOT MENTIONED  IN QUESTION THEN USE ‘ALL’.
- IF MENTIONED THEN CHOSE RESPECTIVE TO QUETION EITHER ‘ALL’ OR ‘ANY’

</aside>

write a query to display details of emp earning more than CLERK

```sql
SELECT * 
FROM EMP 
WHERE SAL > ALL ( 
		SELECT SAL 
		FROM EMP 
		WHERE JOB='CLERK'
);
```

### ANY

- *ANY* operator compares a value against a set of values returned by a subquery.
- It returns *TRUE* if **any one** of the values in the subquery satisfies the condition.
- It is often used with comparison operators like *=*, *<*, *>*,   ≥, ≤ etc.

<aside>
❓

WAQTD details of emp earning more than any of clerk

```sql
SELECT * FROM EMP WHERE SAL > ANY (
	SELECT SAL FROM EMP WHERE JOB = 'CLERK'
);
```
