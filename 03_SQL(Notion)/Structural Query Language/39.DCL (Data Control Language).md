# DCL (Data Control Language)

This statement is used to control the flow of the data between the users.

## 1) Grant:

- This statement is used to give a permission to the user.
- Syntax:

  ```sql
  GRAND SQL_STATMENT (SELECT/ ALL)
  ON TABLE_NAME
  TO USER_NAME;
  ```
- Example:

  ```sql
  GRAND SELECT 
  ON EMP 
  TO HR;
  ```

  To  access data of system user from HR user use

  ```sql
  SELECT * 
  FROM SYSTEM.EMP;
  ```

## 2) Revoke:

- This statement is used to take back the permission from the user.
- Syntax:

  ```sql
  REVOKE SQL_STATEMENT
  ON TABLE_NAME
  FROM USER_NAME;
  ```
- Example:

  ```sql
  REVOKE SELECT
  ON EMP 
  FROM HR;
  ```

<aside>
💡

- To see user use `SHOW USER;`
- To  connect use `CONN` OR `CONNECT;`
- To see all tables use `SELECT * FROM TAB`

</aside>
