# INNER JOIN

- It is used to obtain only matching records present between the tables.
- Always pass conditions in where Clouse. ON Clouse is only for join condition, where condition in ON Clouse might give error.
  | ANSI(Ameriacan national standard institute)                                                | ORACLE                                                                                     |
  | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ |
  | SELECT COLUMN-NAME/EXPRESSION FROM TABLE-NAME1 INNER JOIN TABLE_NAME2 ON <JOIN_CONDITION>; | SELECT COLUMN_NAME/EXPRESSION FROM TABLE TABLE_NAME1, TABLE_NAME2  WHERE <JOIN_CONDITION>; |
  | TABLE1.COLUMN_NAME=TABLE2.COLUMN_NAME                                                      | EMP.DEPTNO=DEPT.DEPTNO                                                                     |

WAQTD DETAILS OF EMP AND THEIR DEPT DETAILS

```sql
SELECT * 
FROM EMP,DEPT
WHERE EMP.DEPTNO=DEPT.DEPTNO;
```

```sql
SELECT *
FROM EMP INNER JOIN DEPT
ON EMP.DEPTNO=DEPT.DEPTNO;
```

WAQTD EMP NAMES ALONG WITH THEIR DEPT NAMES IF EMP ARE EARNING MORE THAN 2000 AND THEY ARE HIRED AFTER 1980

```sql
SELECT ENAME,DNAME,SAL,HIREDATE
FROM EMP INNER JOIN DEPT
ON EMP.DEPTNO=DEPT.DEPTNO 
WHERE SAL>2000 AND HIREDATE>='1-JAN-1981'; 
```

WAQTD NO OF EMP WORKING IN EACH DEPT IF THEY ARE WORKING IN LOC OF NEW YORK AND EARNING MORE THAN SMITH

```sql
SELECT COUNT(*) AS NO_OF_EMP,EMP.DEPTNO
FROM EMP INNER JOIN DEPT
ON EMP.DEPTNO=DEPT.DEPTNO 
WHERE LOC='NEW YORK' AND SAL>(
		SELECT SAL 
		FROM EMP 
		WHERE ENAME ='SMITH'
)
GROUP BY EMP.DEPTNO; 
```

WAQTD DETAILS OF EMP ALONG WITH THEIR LOCATION AND DEPT NAME IF EMP ARE HIRED AFTER CLURK, EARNING MORE THAN SALSMAN, WORKING IN SAME DEPT NO AS PRESIDENT AND THEY HAVE CHAR ‘A’ OR  CHAR ‘S’ IN THEIR NAME

```sql
SELECT EMP.*,LOC,DNAME 
FROM EMP INNER JOIN DEPT
ON EMP.DEPTNO=DEPT.DEPTNO 
WHERE HIREDATE > ALL (
		SELECT HIREDATE
		FROM EMP 
		WHERE JOB='CLERK'
) AND SAL> ALL(
		SELECT SAL 
		FROM EMP 
		WHERE JOB='SALESMAN'
) AND EMP.DEPTNO = (
		SELECT DEPTNO 
		FROM EMP 
		WHERE JOB='PRESIDENT'
) AND (ENAME LIKE '%A%' OR ENAME LIKE '%S%');
```
