# Data Query Language(DQL)

- In **DQL** we perform query on tables and extract the required information.
- DQL contains **4 key concepts**:

---

---

# **1️⃣ SELECT**

- **SELECT** is used to **retrieve data from both rows and columns from a table**.
- It is used together with *projection* and *selection*.

### ✔ Example

```sql
SELECT * FROM Employees;
```

---

# **2️⃣ PROJECTION**

- Projection is used to **retrieve only specific columns** from a table.
- Helps remove unnecessary columns and reduces output size.
- Projection is performed using the **SELECT column-list** part of the query.
- Syntax:

```sql
SELECT * [DISTINCT] COLUMN_NAME/EXPRESSION [ALIAS] 
FROM TABLE_NAME;

// [****] - "****" IS OPTIONAL
```

### ✔ Example

```sql
SELECT name, salary FROM Employees;
```

---

# **3️⃣ SELECTION**

- Used to **filter and retrieve only specific rows** from a table.
- It is performed using the **WHERE** clause.
- Returns only those rows that satisfy **the condition** in **WHERE `clause`**.
- Usually combined with **Projection (columns)** and **SELECT** for data retrieval.
- Without Selection, the query returns **all rows** of the table.
- Syntax:

```sql
SELECT * | [DISTINCT] column_name | expression [ALIAS]
FROM table_name
WHERE <filter_condition>;
```

# **📌 Examples**

### **❓ Get details of employees whose salary is greater than 2000**

```sql
SELECT *
FROM EMP
WHERE SAL > 2000;

```

---

### **❓ Get names and jobs of employees working in department 10**

```sql
SELECT ENAME, JOB
FROM EMP
WHERE DEPTNO = 10;

```

---

### **❓ Get employees hired after year 81**

```sql
SELECT ENAME, HIREDATE
FROM EMP
WHERE HIREDATE > '01-JAN-81';

```

---

### **❓ Get name, salary, and annual salary of CLERK S**

```sql
SELECT ENAME, SAL, SAL*12 AS ANNUAL_SAL
FROM EMP
WHERE JOB = 'CLERK';

```

---

# **4️⃣ JOINS**

- Joins are used to **retrieve data from multiple tables at the same time**.
- They connect tables using a **common column**.
- Useful for relational databases where data is stored in separate tables.

### ✔ Example

```sql
SELECT E.name, D.department_name
FROM Employees E JOIN Department D 
ON E.dept_id = D.dept_id;

```
