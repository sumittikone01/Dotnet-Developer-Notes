# UPDATE Statement

---

- The `UPDATE` statement is used to **modify existing records** in a table.
- It allows updating **one or more columns** for **specific rows**.

---

## **Syntax**

```sql
UPDATE table_name
SET column1 = value1, column2 = value2
WHERE condition;
```

---

## **Updating a Single Record**

Use `WHERE` to target one specific row.

```sql
UPDATE Customers
SET ContactName = 'Alfred Schmidt', City = 'Frankfurt'
WHERE CustomerID = 1;
```

✔ Updates **only** the row where `CustomerID = 1`.

---

## **Updating Multiple Records**

Use a condition that matches more than one row.

```sql
UPDATE Customers
SET ContactName = 'Juan'
WHERE Country = 'Mexico';

```

✔ Updates **all customers** whose `Country` is **Mexico**.

---

## **Important Notes**

- **`WHERE` clause is crucial**.

  Without it, **every row** in the table will be updated.

  ```sql
  UPDATE Customers
  SET ContactName = 'Juan';
  ```

  ❗ Updates *all*  rows.
- You can use **subqueries** inside `SET` to update values based on another table.

  ```sql
  UPDATE dependents
  SET last_name = (
      SELECT last_name
      FROM employees
      WHERE employee_id = dependents.employee_id
  );

  ```
- Always **double-check the condition** before running an update.
