# EXPRESSIONS

1. Combination of Operator and Operand is called as EXPRESSION
2. There are two components in expressions: Operand and Operator(+ , - , *, /).
3. There are two types in Operand: Column name and Literals( Direct values).
4. There are three types in literals:
   1. Character literal
   2. Number Literal,
   3. Date Literal.

<aside>
💡

### Note -

1. Character literal and date literal should be enclosed within single quotes.
2. The specified date format which is given by oracle :
   ‘DD-MON-YY’  OR ‘DD-MON-YYYY’ .

</aside>
