# 41.SQL Server and SSMS Basics

---

## 📌 What is SQL Server

> **SQL Server** is Microsoft's Relational Database Management System (RDBMS)
> that stores, manages, and retrieves data using T-SQL (Transact-SQL).

- Full name: **Microsoft SQL Server**
- Language used: **T-SQL** (Transact-SQL) — Microsoft's extended version of SQL
- Used in: enterprise apps, ASP.NET projects, banking, ERP systems
- Your company stack uses **SQL Server** — everything you write will be T-SQL

---

## 📌 What is SSMS

> **SSMS (SQL Server Management Studio)** is a free GUI tool by Microsoft
> to connect to SQL Server and run queries, manage databases, tables, stored procedures, etc.

Think of it like this:

```
SQL Server  =  The engine (the actual database)
SSMS        =  The dashboard / cockpit to control that engine
```

## 📌 T-SQL vs Standard SQL

SQL Server uses **T-SQL** — it follows standard SQL rules but adds extra features.

| Standard SQL                                   | T-SQL Addition                                  |
| ---------------------------------------------- | ----------------------------------------------- |
| `SELECT`, `INSERT`, `UPDATE`, `DELETE` | All supported + extended                        |
| No variables                                   | `DECLARE @var INT`                            |
| No IF/ELSE                                     | `IF condition BEGIN...END ELSE BEGIN...END`   |
| No loops                                       | `WHILE`, `CURSOR`                           |
| No print                                       | `PRINT 'message'`                             |
| No try/catch                                   | `BEGIN TRY...END TRY BEGIN CATCH...END CATCH` |
| No TOP keyword                                 | `SELECT TOP 10 * FROM Table`                  |

## 📌 Common T-SQL Commands to Know

```sql
-- See all databases on the server
SELECT name FROM sys.databases;

-- Switch to a specific database
USE LoginDB;

-- See all tables in current database
SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_TYPE = 'BASE TABLE';

-- See structure of a table (columns, types, nullability)
SP_HELP Users;
-- OR
SELECT COLUMN_NAME, DATA_TYPE, IS_NULLABLE
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_NAME = 'Users';

-- See all stored procedures
SELECT name FROM sys.procedures;

-- Check SQL Server version
SELECT @@VERSION;

-- Check current database
SELECT DB_NAME();

-- Check current user
SELECT SYSTEM_USER;
```

## 📌 SQL Server Data Types (T-SQL)

> These are specific to SQL Server — slightly different from Oracle/MySQL.

### Text / String

| Type              | Max Size             | Use When                                             |
| ----------------- | -------------------- | ---------------------------------------------------- |
| `CHAR(n)`       | 8000 chars           | Fixed-length text (e.g. country code 'IN')           |
| `VARCHAR(n)`    | 8000 chars           | Variable-length text (names, emails)                 |
| `NVARCHAR(n)`   | 4000 chars (Unicode) | Text with multiple languages / Hindi / special chars |
| `NVARCHAR(MAX)` | ~2GB                 | Large Unicode text                                   |
| `TEXT`          | 2GB                  | Old type — avoid, use`VARCHAR(MAX)`               |

> 🔑 **Your company uses `NVARCHAR`** for most text — it supports all languages.

### Numbers

| Type             | Range             | Use When                          |
| ---------------- | ----------------- | --------------------------------- |
| `INT`          | -2.1B to +2.1B    | IDs, counts, ages                 |
| `BIGINT`       | Much larger       | Large IDs, transaction counts     |
| `SMALLINT`     | -32,768 to 32,767 | Small numbers                     |
| `DECIMAL(p,s)` | Exact precision   | Money, percentage                 |
| `FLOAT`        | Approximate       | Scientific data (avoid for money) |
| `BIT`          | 0 or 1            | Boolean — IsLocked, IsActive     |

### Date and Time

| Type          | Format              | Use When                    |
| ------------- | ------------------- | --------------------------- |
| `DATE`      | YYYY-MM-DD          | Birth dates, calendar dates |
| `DATETIME`  | YYYY-MM-DD HH:MM:SS | Log timestamps              |
| `DATETIME2` | More precision      | Preferred over DATETIME     |
| `GETDATE()` | Function            | Gets current date and time  |

## 📌 Creating Your First Database and Table

```sql
-- Step 1: Create a database
CREATE DATABASE LoginDB;

-- Step 2: Use it
USE LoginDB;

-- Step 3: Create a table
CREATE TABLE Users
(
    UserId         NVARCHAR(50)  PRIMARY KEY,
    PasswordHash   NVARCHAR(255) NOT NULL,
    Role           NVARCHAR(20)  DEFAULT 'User',
    FailedAttempts INT           DEFAULT 0,
    IsLocked       BIT           DEFAULT 0,
    CreatedAt      DATETIME2     DEFAULT GETDATE()
);

-- Step 4: Insert a row
INSERT INTO Users (UserId, PasswordHash, Role)
VALUES ('sumit', 'hashed_password_here', 'Admin');

-- Step 5: See the data
SELECT * FROM Users;
```

## ❓ Interview Questions

**Q: What is T-SQL and how is it different from standard SQL?**
A: T-SQL is Microsoft's extended version of SQL used in SQL Server. It adds variables (`DECLARE`), conditionals (`IF/ELSE`), loops (`WHILE`), error handling (`TRY/CATCH`), and SQL Server-specific functions like `GETDATE()`, `TOP`, `ISNULL()`.

**Q: What is SSMS?**
A: SQL Server Management Studio — a free Microsoft GUI tool to connect to SQL Server, write queries, manage databases, tables, stored procedures, and more.

**Q: Difference between CHAR, VARCHAR, and NVARCHAR in SQL Server?**

|         | CHAR             | VARCHAR           | NVARCHAR            |
| ------- | ---------------- | ----------------- | ------------------- |
| Length  | Fixed            | Variable          | Variable (Unicode)  |
| Storage | Always n bytes   | Only actual chars | 2 bytes per char    |
| Use for | Codes, fixed IDs | English text      | Multi-language text |
