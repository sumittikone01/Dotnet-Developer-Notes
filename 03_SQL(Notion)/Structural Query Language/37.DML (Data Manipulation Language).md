# DML (Data Manipulation Language)

- DML is used to **manipulate data** inside database tables — **INSERT, UPDATE, DELETE**.
- All DML operation we perform on table is called transactions.
- All DML operation are performed temporarily.
- All DML Operations are not auto commit

# 1) INSERT:

- It is used to insert the data into the table.

## First way:

- Syntax:

  ```sql
  INSERT INTO TABLE_NAME VALUES( V1, V2, V3....Vn)
  ```
- Example:

  ```sql
  INSERT INTO DEPARTMENT VALUES(
  	101, 'ACCOUNTING'
  );
  ```

## Second way:

- Syntax:

  ```sql
  INSERT INTO TABLE_NAME VALUES( &COLUMN_NAME1, &COLUMN_NAME2,&COLUMN_NAME3....&COLUMN_NAMEn)
  ```
- Example:

  ```sql
  INSERT INTO DEPARTMENT VALUES( &DEPTNO, &DNAME);
  ```

# 2) UPDATE

- It is used to update the records present inside the table
- Syntax:

  ```sql
  UPDAE TABLE_NAME
  SET COL_NAME1=VALUE1, COL_NAME2=VALUE2, COL_NAME3=VALUE3.....
  [WHERE <FILTER_CONDITION>] ------ OPTIONAL
  ```
- Example:

  ```sql
  UPDATE DEPARTMENT
  SET DEPTNO=106, DNAME='D6'
  WHERE DEPTNO=102;
  ```

  [**`UPDATE` Statement**](<UPDATE%20Statement%202af7ce6c5c258083bd44cf28b10556ae.md>)

# 3) DELETE

- It is used to delete the records from the table temporarily
- Syntax:

```sql
DELETE FROM TABLE_NAME
[WHERE <FILTER_CONDITION>] ---------OPTIONAL
```

- Example:

```sql
DELETE FROM DEPARTMENT
WHERE DEPTNO = 106;
```

# Difference between delete, drop and truncate

| **DELETE**                                          | **DROP**                                              | **TRUNCATE**                               |
| --------------------------------------------------------- | ----------------------------------------------------------- | ------------------------------------------------ |
| Used to delete**selected records** (with filtering) | Used to delete the**entire table (structure + data)** | Used to delete**all records** from a table |
| Supports**WHERE** clause                            | Does**not** support WHERE                             | Does**not** support WHERE                  |
| It is a**DML** command                              | It is a**DDL** command                                | It is a**DDL** command                     |
| **Rollback possible**                               | **Flashback** is possible (restores entire table)     | **Rollback/Flashback NOT possible**        |
| `DELETE FROM table_name WHERE condition;`               | `DROP TABLE table_name;`                                  | `TRUNCATE TABLE table_name;`                   |
