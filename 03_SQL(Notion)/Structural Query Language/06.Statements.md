# Statements

## Statements

1. Statements are used to perform CRUD Operations on the database.
2. Types Of Statements
   1. **DATA DEFINATION LANGUAGE (DDL)**
      1. CREAT
      2. ALTER
      3. DRO0
      4. RENAME
      5. TRUNCATE
   2. **DATA MANIPULATION LANGUAGE (DML)**
      1. INSERT
      2. UPDATE
      3. DELETE
   3. **TRANSACTION CONTROL LANGUAGE (TCL)**
      1. COMMIT
      2. ROLLBACK
      3. SAVEPOINT
   4. DATA CONTROL LANGUAGE (DCL)
      1. GRANT
      2. REVOKE
   5. **DATA QUERY LANGUAGE (DQL)**
      1. SELECT
      2. SELEECTION
      3. PROJECTION
      4. JOINS
