# Natural Join

It has 2 behaviors

1. If there is a connection between 2 tables then it will act like INNER JOIN/EQUI JOIN

   <aside>
    ❓

   It always check the common column while inner join

   </aside>
2. if there is a no connection between 2 tables then it will act like CROSS JOIN/CARTESIAN JOIN
3. ANSI Syntax:

   ```sql
   SELECT COLUMN-NAME/EXPRESSION 
   FROM TABLE-NAME1 NATURAL JOIN TABLE_NAME2;
   ```
4. Example:

   ```sql
   SELECT *  
   FROM EMP NATURAL JOIN DEPT;
   ```
