# REPLACE()

Sr_no: 9

## Replace:

1. It used to replace a string with another new string which is present inside the original string.
2. Syntax: REPLACE ( ‘ORIGINAL_STRING’ , ‘OLD_STRING’, [NEW_STRING])

<aside>
❓

EXAMPLE:

```sql
SELECT REPLACE('MUMBAI','M','B') 
FROM DUAL
```

```sql
SELECT REPLACE('MUMBAI','MUM') 
FROM DUAL
```

</aside>

<aside>

WAQTD NUMBER OF TIMES CHAR ‘A’ PRESENT IN ‘AKASH’ STRING

```sql
SELECT LENGTH('AKASH') - LENGTH( REPLACE('AKASH','A'))
```
