## INSTR() :

1. It is used to extract position of a string  which is present inside the original string.
2. It does not follows negative positioning.
3. Syntax : INSTR(’ORIGINAL STRING’, ‘STRING’, POSITION, [OCCURRENCE]) 

<aside>
❓ Example:

```sql
SELECT INSTR('MALAYALAM','L',3) 
FROM DUAL
```

```sql
SELECT INSTR('MALAYALAM', 'LA',1,2) 
FROM DUAL;
```

</aside>

<aside>
❓ WAQTD DETAILS OF EMP IF THEY HAVE CHAR ‘A’ IN THEIR NAME

```sql
SELECT * 
FROM EMP
WHERE INSTR(ENAME,'A',1)>0;
```
