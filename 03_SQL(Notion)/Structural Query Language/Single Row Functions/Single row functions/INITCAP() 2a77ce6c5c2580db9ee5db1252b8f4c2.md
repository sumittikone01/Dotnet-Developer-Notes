# INITCAP()

Sr_no: 4

## INITCAP();

1. This function is used to convert the initial char of each word in a string to uppercase.
2. example :
    
    ```sql
    SELECT INITCAP('this is sql batch by rajath')
    FROM DUAL;
    ```
