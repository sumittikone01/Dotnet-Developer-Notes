# UPPER

Sr_no: 2

## UPPER:

- This function is used to convert the given string into  upper case.
- Syntax: UPPER(’STRING’)
    
    ```java
    UPPER('STRING')
    ```
    
- EXAMPLE :
    
    ```sql
    SELECT UPPER('THIS IS A SQL BATCH')
    FROM DUAL;
    ```
