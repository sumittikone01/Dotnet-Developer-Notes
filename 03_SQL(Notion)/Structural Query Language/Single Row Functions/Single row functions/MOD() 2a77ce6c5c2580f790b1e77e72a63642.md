# MOD()

Sr_no: 7

## MOD

1. It is used to obtain reminder of the given numbers
2. Syntax:  MOD(VALUE1, VALUE2)

<aside>
❓ EXAMPLE

```sql
SELECT MOD(5,2) 
FROM DUAL;
```

```sql
SELECT MOD(23,3) 
FROM DUAL;
```

![image.png](MOD()/image.png)

</aside>

<aside>
❓ WAQTD DETAILS OF EMP EARNING EVEN SALARIES

```sql
SELECT * 
FROM EMP
WHERE MOD(SAL,2)=0;
```

![image.png](MOD()/image%201.png)

</aside>

<aside>
❓ WAQTD DETAILS OF EMP AT ODD POSITIONS OF THE EMP TABLE

```sql
SELECT * 
FROM (SELECT EMP.*, ROWNUM AS SR_NO FROM EMP)
WHERE MOD(SR_NO,2)=1;
```

![image.png](MOD()/image%202.png)

</aside>

<aside>
❓ WAQTD DETAILS OF EMP IF THEY ARE EARNING IN MULTIPLES OF 3

```sql
SELECT * 
FROM EMP
WHERE MOD(SAL,3)=0;
```
