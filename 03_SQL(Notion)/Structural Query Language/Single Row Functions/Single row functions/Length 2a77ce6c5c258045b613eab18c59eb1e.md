# Length

Sr_no: 1

## Length :

- It is used to return length of the characters or number present inside the given column.
- It also used to return length of char or varchar data type (count of charactors)
- Example:

```sql
SELECT LENGTH(ENAME), ENAME 
FROM EMP;
```
