# NVL()

Sr_no: 14

## NVL(NULL VALUE LOGIC)

- It is used to eliminate the side effects using null in arithmetic operation.
- Syntax:  NVL(Argument1, Argument2)

<aside>
❓

Example1: WAQTD NAME AND TOTAL EARNING OF EACH AND EVERY EMP (SAL+ CUMMITION)  

```sql
SELECT ENAME,SAL+ COMM AS TOTAL_EARNING
FROM EMP; 
```

![image.png](NVL()/image.png)

Arithmatic operation between num and null value return’s null value at this time nvl() comes into use

```sql
SELECT ENAME,SAL+ NVL(COMM,0) AS TOTAL_EARNING
FROM EMP; 
```

![image.png](NVL()/image%201.png)

</aside>

<aside>
❓

WAQTD TOTAL SAL OF EACH  EMP BUT IF THEY ARE NOT EARNING COMM GIVE THEM BONUS OF 500RS 

```sql
SELECT ENAME,SAL+ NVL(COMM,500) AS TOTAL_EARNING
FROM EMP; 
```
