# TRUNC()

Sr_no: 11

## Trunc:

1. It is used to round off the given number to the smaller value. 

<aside>
❓

Examples: 

```sql
SELECT TRUNC(4.8) 
FROM DUAL;
```

```sql
SELECT TRUNC(434.1) 
FROM DUAL
```
