# SUBSTR()

Sr_no: 5

## SUBSTR():

1. This function is used to extract the part of the string from the given original string.
2. SYNTAX: 
    
    ```sql
    SELECT SUBSTR('ORIGINAL_STRING', POSITION,[LENGTH]) 
    FROM TABLENAME
    ```
    
3. EXAMPLE: 
    
    ```sql
    SELECT SUBSTR('BANGLORE', 5, 3) 
    FROM DUAL;
    ```
