# Union

The **UNION** operator is used to **combine the result sets of two or more SELECT statements** into a single result.

### **Key Points**

- It **removes duplicate rows** by default.
- Each SELECT must have:
  - The **same number of columns**
  - Columns in the **same order**
  - **same datatypes** in corresponding columns
- The result is a **vertical combination** of rows from both queries.
- ORDER BY can be applied **only at the end** of the final SELECT.

### **Syntax:**

```sql
SELECT column_list FROM table1
UNION
SELECT column_list FROM table2;
```

Example:

```sql
SELECT * FROM EMP LEFT JOIN DEPT ON EMP.DEPTNO=DEPT.DEPTNO 
UNION
SELECT * FROM EMP RIGHT JOIN DEPT ON EMP.DEPTNO=DEPT.DEPTNO;
```
