# Data Types

### Data Types

It is Used to describe which type of data we can store in a column or particular memory location.

1. CHAR
2. VARCHAR/ VARCHAR2
3. DATE
4. NUMBER
5. LARGE OBJECT
   1. CHARACTER LARGE OBJECT ( CLOB )
   2. BINARY LARGE OBJECT ( BLOB )

### 1. CHAR

1. It is use to store Character such as
   1. ‘A-Z’
   2. ‘a-z’
   3. special character ‘@’, ‘#’, ‘$’, ‘&’
   4. ‘0-9’
   5. Alpha Numerics ‘34D78D8A’
2. When ever we assign CHAR datatype we must have to mention size for it
3. The Default size of CHAR is 1 .
4. When we assign CHAR Datatype we must have to enclosed the characters within single quotes.
5. Max Size of CHAR IS 2000
6. CHAR Datatype Follows Fixed Length Memory Allocation.

## 2.1  VARCHAR

1. It is use to store Character such as
   1. ‘A-Z’
   2. ‘a-z’
   3. special character ‘@’, ‘#’, ‘$’, ‘&’
   4. ‘0-9’
   5. Alpha Numerics ‘34D78D8A’
2. Whenever we assign VARCHAR datatype we must not mention size for it If mentioned Then There is No Default size of VARCHAR Like we have for the CHAR .
3. When we assign VARCHAR Datatype we must have to enclosed the characters within single quotes.
4. Max Size of VARCHAR IS 2000
5. VARCHAR Datatype Follows Variable Length Memory Allocation.

<aside>
❓

Interview Question : CHAR Vs VARCHAR

| **CHAR**                                           | **VARCHAR**                                                  |
| -------------------------------------------------------- | ------------------------------------------------------------------ |
| it is used to store character string of Fixed-length     | it is used to store character string of Variable-length            |
| Pads extra spaces if data is shorter than defined size   | Stores only actual characters (no padding)                         |
| Usually better performance (because fixed size)          | Slightly slower (variable size handling)                           |
| Storage size = defined length (n bytes)                  | Storage size = actual string length                                |
| Best for data of**same** length (e.g., codes, IDs) | Best for data of**variable** length (e.g., names, addresses) |

</aside>

## 2.2 VARCHAR2

1. It is Updated version of The VARCHAR datatype
2. Syntax

```sql
VARCHAR2(SIZE)
```

1. In VARCHAR2 we can store up to 4000 characters
2. Whenever we assign VARCHAR datatype with 2000+ characters automatically it will convert into VARCHAR2 datatype.

## 3. DATE

1. It is use to store Date in some specified format.
2. Syntax

```sql
DATE
```

1. There are format we need to follow to store the date
   1. ‘DD-MON-YYYY’ → ‘12-MAY-2002’
   2. ‘DD-MON-YY’ → ‘12-MAY-02’
   3. use to filter or sort the data

## 4. NUMBER

![WhatsApp Image 2025-09-24 at 14.15.26_86909a09.jpg](<Data%20Types/WhatsApp_Image_2025-09-24_at_14.15.26_86909a09.jpg>)

1. It is use to store the numeric data
2. it takes 2 arguments.
   1. Precision
      1. it is use to store the integer type of data
      2. Max Size : 38
   2. Scale
      1. it is use to store the Decimal values
      2. Max Size : 127
3. Number of memory block allocation will be = MAX(Precision,Scale)
4. Number datatype is combination of the Integer and float data type.
5. Syntax → [OPTIONAL]

```sql
NUMBER(PRECISION,[SCALE])
```

1. 23000.232
   1. precision - 8
   2. scale - 3

## 5. LARGE OBJECT

### 5.1 CHARACTER LARGE OBJECT (CLOB)

1. It is use to store Large amount of character upto 4GB
2. Disadvantage
   1. no size argument.
3. Syntax

```sql
CLOB
```

### 5.2 BINARY LARGE OBJECT (BLOB)

1. it is use to store images, audios, videos in the form of binary
2. Syntax

```sql
BLOB
```
