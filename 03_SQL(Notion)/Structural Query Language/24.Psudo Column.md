# Psudo Column

- pseudo columns are the false columns present in each and every table and must be called explicitly
- There are 2 types of pseudo columns
  1. row id
  2. Row Num

## 1. Row Id

- Row id is an 18 digit address of the records present inside the tables.
- row id is unique.
- *It is always static.*
- It generates  while insertion of the records.
- It is a fastest or quickest way to access or delete the records.

```sql
SELECT ROWID, EMP.*
FROM EMP;
```

![image.png](<Psudo%20Column/image.png>)

## 2. Row Num

- Row num are the serial numbers assigned to the records In result table .
- It generates at the time of Execution.
- Row Num is dynamic.
- Row Num always starts with 1.

from emp

		select sal, rownum as sr_no from (

		where sr_no = 3
		or sr_no = ( select count(*)-2 from emp ));
