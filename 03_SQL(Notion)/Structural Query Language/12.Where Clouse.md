# Where Clouse

- Where is used to **filter rows** based on a condition written inside the WHERE clause.
- It checks each row **one by one** to see if it satisfies the condition.
- The **FROM clause executes first**, and then the WHERE clause filters the rows returned by FROM.
- Supports **multiple conditions** using logical operators like `AND`, `OR`, and `NOT`.
- WHERE works with **SELECT, UPDATE, and DELETE** statements.
