# JOINS

- JOINS are used to retrieve data from multiple tables simultaneously.
- Types of Joins:
  1. CARTATION JOIN/ CROSS JOIN
  2. INNER JOIN
  3. OUTER JOIN
     1. LEFT OUTER JOIN
     2. RIGHT OUTER JOIN
     3. FULL OUTER JOIN
  4. NATURAL JOIN
  5. SELF JOIN
