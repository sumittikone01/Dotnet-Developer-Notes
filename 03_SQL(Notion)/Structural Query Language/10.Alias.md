# Alias

## **What is an Alias?**

An **alias** is a temporary alternative name given to a **column, expression** or a **table** to make SQL queries shorter, cleaner, and easier to understand.

---

# **1️⃣ COLUMN ALIAS**

Used to rename a column or expression in the result table.

### **Key Rules**

- Alias changes the name only in the query result, not in the real table.
- Can be used **with or without `AS`**.
- Use **double quotes `“ ”`** for aliases that contain **multiple words**.

### **Examples**

```sql
SELECT ENAME NAME FROM EMP;
SELECT ENAME AS NAME FROM EMP;

SELECT ENAME "NAME COLUMN" FROM EMP;
SELECT SAL*12 AS ANNUAL_SALARY FROM EMP;
SELECT SAL*12 AS "ANNUAL SALARY" FROM EMP;
```

---

# **2️⃣ TABLE ALIAS**

Used to give a short name to a table, especially useful in:

- joins
- self-joins
- long table names

### **Key Rules**

- Alias lasts only for that query

### **Examples**

### ✔ **Basic aliases**

```sql
SELECT e.ENAME, d.DNAME
FROM EMP e, DEPT d
WHERE e.DEPTNO = d.DEPTNO;

```

### ✔ **With multiple tables**

```sql
SELECT e.ENAME, m.ENAME AS MANAGER_NAME
FROM EMP e, EMP m
WHERE e.MGR = m.EMPNO;

```

### ✔ **Alias makes query cleaner**

Without alias (bad):

```sql
SELECT EMP.ENAME, EMP.SAL
FROM EMP
WHERE EMP.SAL > 2000;

```

With alias (clean):

```sql
SELECT e.ENAME, e.SAL
FROM EMP e
WHERE e.SAL > 2000;
```

---

# **3️⃣ WHY ALIASES MATTER**

### **Column Alias**

- Makes result table readable
- Used with expressions
- Used when two tables have same column name

### **Table Alias**

- Reduces query size
- Makes joins easier to write
- Required for self-joins
- Resolves ambiguity
