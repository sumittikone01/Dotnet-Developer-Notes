# Group By Clause in SQL

- The `GROUP BY` clause **groups records that have the same values** in specified columns or expressions, so that multi-row (aggregate) functions can be applied to each group separately.
- It **processes data group by group**, not row by row.
- You can pass **column names or expressions** as arguments to the `GROUP BY` clause.
- **Multi-row (aggregate) functions** can be used in the `SELECT` clause along with `GROUP BY`.
- **Group By Expression:**

  Any column name or expression specified in the `GROUP BY` clause is called a **group by expression**.
- After groups are formed, **any clause written after `GROUP BY` (such as `HAVING`) executes group by group**.
- Syntax:

  ```sql
  SELECT group_by_expression, group/aggregate_function
  FROM table_name
  [WHERE <filter_condition>]
  GROUP BY column_name/expression;
  ```

<aside>
💡

Note:

- Any column or expression in the SELECT clause that is not inside a multi-row function must appear in the GROUP BY clause.
- Example:

  ```sql
  SELECT DEPTNO,AVG(SAL)
  FROM EMP
  GROUP BY DEPTNO;
  // It Groups employees by department and calculates average salary per department.
  ```

</aside>

---

## Execution Order

1. **FROM**

   Processes records row by row.
2. **WHERE (if used)**

   Filters records row by row.
3. **GROUP BY**

   Groups data group by group.
4. **SELECT**

   Processes/group data as specified.

## **Practical Notes on `GROUP BY` Clause**

- You can **group by multiple columns** to create more detailed and specific groups.
- Aggregate functions like **SUM(), AVG(), COUNT(), MIN(), and MAX()** are most commonly used with `GROUP BY`.
- In the `SELECT` clause, **every non-aggregate column must appear in the `GROUP BY` clause** (otherwise SQL cannot form proper groups).
