# OUTER JOIN

It is used to obtain unmatched records

In Outer join we have 3 types

1. left outer join
2. right outer join
3. full outer join

# 1) Left Outer Join:

- It is used to obtain unmatched records only from left table along with matching records

| ANSI(Ameriacan national standard institute)                                                       | ORACLE                                                                                               |
| ------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| SELECT COLUMN-NAME/EXPRESSION FROM TABLE-NAME1 LEFT [OUTER] JOIN TABLE_NAME2 ON <JOIN_CONDITION>; | SELECT COLUMN_NAME/EXPRESSION FROM TABLE TABLE_NAME1, TABLE_NAME2  WHERE TN1.COLNAME=TN2.COLNAME(+); |
| TABLE1.COLUMN_NAME=TABLE2.COLUMN_NAME                                                             | EMP.DEPTNO=DEPT.DEPTNO(+)                                                                            |

<aside>
❓

WAQTD DETAILS OF EMP AND THEIR DEPT EVEN IF EMP DOESENT WORK IN ANY DEPARTMENT

```sql
SELECT E.*,D.*
FROM EMP E LEFT JOIN DEPT D
ON E.DEPTNO=D.DEPTNO;
```

OR

```sql
SELECT ENAME,DNAME,E.DEPTNO 
FROM EMP E, DEPT D
WHERE E.DEPTNO=D.DEPTNO(+);
```

</aside>

<aside>
❓

WAQTD CUSTOMER AND THEIR PRODUCT DETAILS IF CUSTOMER HAS NOT PURCHASED ANY PRODUCT AND PRICE OF THE PRODUCT SHOULD BE MORE THAN 2000

| CUSTOMER | PRODUCT |  |
| -------- | ------- | - |
| CID      | PID     |  |
| CNAME    | PNAME   |  |
| PHNO     | PRICE   |  |
| PID      |         |  |

```sql
SELECT CUSTOMER.*, PRODUCT.*
FROM CUSTOMER C LEFT JOIN PRODUCT P
ON C.PID=P.PID
WHERE PRICE> 2000 AND C.PID IS NULL;
```

</aside>

<aside>
❓

WAQTD EMP AND THEIR DEPT DETAILS EVEN IF EMP DOESENT WORK IN ANY DEPARTMENT & THEY ARE HIRED AFTER 1980 & THEY HAVE CHAR A OR CHAR S IN THIR NAME

```sql
SELECT E.*, D.*
FROM EMP E LEFT JOIN DEPT D
ON E.DEPTNO=D.DEPTNO
WHERE E.HIREDATE>='1-JAN-1981' AND (ENAME LIKE '%A%' OR ENAME LIKE '%S%');
```

</aside>

# 2) Righter Outer Join:

- It is used to obtain unmatched records only from right table along with matching records

| ANSI(Ameriacan national standard institute)                                                        | ORACLE                                                                                               |
| -------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| SELECT COLUMN-NAME/EXPRESSION FROM TABLE-NAME1 RIGHT [OUTER] JOIN TABLE_NAME2 ON <JOIN_CONDITION>; | SELECT COLUMN_NAME/EXPRESSION FROM TABLE TABLE_NAME1, TABLE_NAME2  WHERE TN1.COLNAME(+)=TN2.COLNAME; |
| TABLE1.COLUMN_NAME=TABLE2.COLUMN_NAME                                                              | EMP.DEPTNO(+)=DEPT.DEPTNO                                                                            |

<aside>
❓

WAQTD DETAILS OF EMP AND THEIR DEPT EVEN IF DEPT DONT HAVE ANY EMP WORKING

```sql
SELECT *
FROM EMP E RIGHT JOIN DEPT D
ON E.DEPTNO=D.DEPTNO;
```

OR

```sql
SELECT *
FROM EMP E, DEPT D
WHERE E.DEPTNO(+)=D.DEPTNO;
```

</aside>

<aside>
❓

WAQTD DETAILS OF CUSTOMER AND PRODUCT EVEN IF PRODUCT IS NOT PURCHASED BY ANY CUSTOMER

```sql
SELECT * 
FROM CUSTOMER C RIGHT JOIN PRODUCT P
ON C.PID=P.PID;
```

</aside>

# 3) FULL OUTER JOIN:

- It is used to obtain unmatched records from both the table, along with matching records.
- ANSI Syntax:

  ```sql
  SELECT COLUMN-NAME/EXPRESSION 
  FROM TABLE-NAME1 FULL[OUTER] JOIN TABLE_NAME2 
  ON <JOIN_CONDITION>;
  ```

<aside>
❓

WAQTD EMP AND DEPT DETAILS IF EMP ARE NOT WORKING IN ANY DEPT AND DEPT ALSO HAVE NO EMPS

```sql
SELECT * 
FROM EMP FULL JOIN DEPT
WHERE EMP.DEPTNO=DEPT.DEPTNO;
```

</aside>
