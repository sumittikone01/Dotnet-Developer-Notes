# Types Of Subquery

1. Single row subquery
2. Multirow subquery
3. Nested Subquery
4. Co-related Subquery
5. Single Row Subquery-

   1. ***If subquery returns single output then it is called as Single-Row Subquery.***
   2. to compare with single row subquery we can use Normal Operators and Special Operators.
6. Multirow Subquery

   1. ***If subquery returns multiple output then it is called as Multi-Row Subquery.***
   2. To compare with multi-row subquery we have to use special operators.

<aside>
💡

> Note- We don't know whether subquery returns single output or multiple output so it is always recommended to use Special Operators

</aside>

1. Nested Subquery:

   1. ***A subquery which is written inside another subquery is called as nested subquery.***
   2. In Nested subquery always executes  inner most query first.
   3. We can Nest up to 255 subqueries.

   <aside>
    ❓

   WAQTD NAME OF EMP WHOSE SALARY IS 3RD MAX

   ```sql
   SELECT ENAME FROM EMP WHERE SAL= (
   	SELECT MAX(SAL) FROM EMP WHERE SAL < (
       SELECT MAX(SAL) FROM EMP WHERE SAL < (
            SELECT MAX(SAL) FROM EMP 
              )));
   ```

WAQTD NAMES OF EMP EARNING SECOND MIN SAL
