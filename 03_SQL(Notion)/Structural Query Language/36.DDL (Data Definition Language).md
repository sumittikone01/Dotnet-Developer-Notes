# DDL (Data Definition Language)

- ***It is used to create an object into the database and deal with that structure of the object.***

# 1) Create:

1. It is used to create a table int a database.
2. Syntax:

```sql
CREATE TABLE TABLE_NAME (
	COLUMN_NAME1 DATATYPE CONSTRAINT,
	COLUMN_NAME2 DATATYPE CONSTRAINT,
	COLUMN_NAME3 DATATYPE CONSTRAINT
);
```

```sql
CREATE TABLE DEPARTMENT(
	DEPTNO NUMBER(3) PRIMARY KEY,
	DNAME VARCHAR(20) NOT NULL
);
```

```sql
CREATE TABLE EMPLOYEES (
	EID NUMBER(3) PRIMARY KEY,
	NAME VARCHAR(20) NOT NULL,
	GENDER VARCHAR(6) NOT NULL,
	PH_NO NUMBER(10) UNIQUE NOT NULL CHECK(LENGTH(PH_NO)=10) CHECK(PH_NO>0)
);
```

# 2) Rename:

1. It is used to change name of existing table.
2. Syntax:

```sql
RENAME OLD_TABLE_NAME TO NEW_TABLE_NAME;
```

```sql
RENAME EMPLOYEES TO EMPLOYEE;
```

# 3) Alter :

- It is used to modify structure of the table
  1. Add a column
  2. Rename a column
  3. Drop the column
  4. Modify the datatype
  5. Modify the constraints (NULL \  NOT NULL)
  6. Add the constraint
  7. Drop the constraint
  8. Assign foreign key

<aside>
💡

With alter we can’t modify constrains except null and not null

</aside>

1. Add a column:

   1. Syntax:

      ```sql
      ALTER TABLE TABLE_NAME
      ADD COUMN_NAME DATATYPE CONSTRAINTS;
      ```
   2. Example

      ```sql
      ALTER TABLE EMPLOYEE
      ADD EMAIL VARCHAR(30) NOT NULL;
      ```
2. Rename a column:

   1. Syntax:

      ```sql
      ALTER TABLE TABLE_NAME
      RENAME COLUMN OLD_COUMN_NAME TO NEW_COLUMN_NAME2;
      ```
   2. Example

      ```sql
      ALTER TABLE EMPLOYEE
      RENAME COLUMN NAME TO ENAME;
      ```
3. Drop a column:

   1. Syntax:

      ```sql
      ALTER TABLE TABLE_NAME
      DROP COLUMN OLD_COUMN_NAME;
      ```
   2. Example

      ```sql
      ALTER TABLE EMPLOYEE
      DROP COLUMN ROLLNO;
      ```
4. Modify a datatype:

   1. Syntax:

      ```sql
      ALTER TABLE TABLE_NAME
      MODIFY COUMN_NAME NEW_DATATYPE;
      ```
   2. Example

      ```sql
      ALTER TABLE EMPLOYEE
      MODIFY ENAME VARCHAR(30);
      ```
5. Modify a constrain (NULL / NOT NULL):

   1. Syntax:

      ```sql
      ALTER TABLE TABLE_NAME
      MODIFY COUMN_NAME DATATYPE NULL/NOT NULL;
      ```
   2. Example

      ```sql
      ALTER TABLE EMPLOYEE
      MODIFY EMAIL VARCHAR(30) NOT NULL;
      ```
6. ADD a constrain :

   - Syntax:

     ```sql
     ALTER TABLE TABLE_NAME
     ADD CONSTRAINT CONSTRAINT_REFERENCE_NAME CONSTRAINT_TYPE(COLUMN_NAME); 
     ```
   - Example;

     ```sql
     ALTER TABLE EMPLOYEE
     ADD CONSTRAINT UNIQUE_MAIL UNIQUE(EMAIL);
     ```

   <aside>
    💡

   **NOTE**:

   - CONSTRAINT_REFERENCE_NAME  can be any thing
   - In CONSTRAINT_TYPE() we can take multiple TABLE_NAME
   - SYNTAX TO SEE CONSTRAINTS

     ```sql
     SELECT CONSTRAINT_NAME, CONSTRAINT_TYPE 
     FROM ALL_CONSTRAINTS
     WHERE TABLE_NAME='EMPLOYEE';
     ```

   </aside>
7. DROP a constrain :

   - Syntax:

     ```sql
     ALTER TABLE TABLE_NAME
     DROP CONSTRAINT CONSTRAINT_REFERENCE_NAME; 
     ```
   - Example:

     ```sql
     ALTER TABLE EMPLOYEE
     DROP CONSTRAINT UNIQUE_MAIL;
     ```
8. ASSIGN FOREIGN KEY:

   Syntax:

   1. Step 1: Create new column in child table

      ```sql
      ALTER TABLE TABLE_NAME
      ADD COLUMN_NAME DATATYPE CONSTRAINT; 
      ```
   2. Step 2: Assign foreign key in child table

      ```sql
      ALTER TABLE TABLE_NAME
      ADD CONSTRAINT CONSTRAINT_REFERENCE_NAME CONSTRAINT_TYPE(COLUMN_NAME) 
      REFERENCES PARENT_TABLE_NAME(COLUMN_NAME)
      ```

   Example

   1. STEP 1

      ```sql
      ALTER TABLE EMPLOYEE
      ADD DEPTNO NUMBER(3); 
      ```
   2. STEP 2

      ```sql
      ALTER TABLE EMPLOYEE
      ADD CONSTRAINT FK_NO FOREIGN KEY(DEPTNO) 
      REFERENCES DEPARTMENT(DEPTNO);
      ```

   Second way to assign foreign key while creating new table

   ```sql
   CREATE TABLE EMPLOYEE (
   	EID NUMBER(3) PRIMARY KEY,
   	NAME VARCHAR(20) NOT NULL,
   	GENDER VARCHAR(6) NOT NULL,
   	PH_NO NUMBER(10) UNIQUE NOT NULL CHECK(LENGTH(PH_NO)=10) CHECK(PH_NO>0),
   	DEPTNO NUMBER(3),
   	CONSTRAINT FK_NO FOREIGN KEY(DEPTNO) REFERENCES DEPARTMENT(DEPTNO)
   );
   ```

# 4) TRUNCATE

- It is used to delete all the records from table permanently.
- Syntax:

```sql
TRUNCATE TABLE TABLE_NAME;
```

Example:

```sql
TRUNCATE TABLE MASTER;
```

# 5) DROP

- Is used to drop an object from the database
- Syntax:

```sql
DROP TABLE TABLE_NAME;
```

Example

```sql
DROP TABLE EMP;
```

<aside>
💡

used when to show tables inside recycle bin use

```sql
SHOW RECYCLEBIN;
```

</aside>

# FlashBack:

- It is used to get back the table from recycle bin
- Syntax:

  ```sql
  FLASHBACK TABLE TABLE_NAME
  TO BEFORE DROP;
  ```
- Example:

  ```sql
  FLASHBACK TABLE DEPT
  TO BEFORE DROP;
  ```

# PURGE:

- It is used when we have to delete a table permanently from a recycle bin
- Syntax:

  ```sql
  PURGE TABLE  TABLE_NAME;
  ```
- Example:

  ```sql
  PURGE TABLE EMP;
  ```
