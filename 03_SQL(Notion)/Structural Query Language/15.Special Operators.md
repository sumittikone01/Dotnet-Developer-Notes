# Special Operatos

## 1) IN (Alternative of The OR Operator) (Multivalued Operator)

- **IN is a multivalued operator** used to compare a column with **multiple values**.
- It returns **TRUE if the column matches any one value** from the list.
- It works the same as writing multiple **OR** conditions.
- Syntax:

  ```sql
  SELECT COLUMN_NAME/EXP
  FROM TABLE_NAME
  WHERE COLUMN_NAME/EXP IN (V1,V2,V3,....,Vn);
  ```
- EXAMPLE:

  ```sql
  SELECT *
  FROM EMP
  WHERE DEPTNO IN (10,20,30,40,);


  				SELECT *
  				FROM EMP
  				WHERE DEPTNO IN (~~10 OR 20~~ );  //NOT ALLOWED
  ```

## 2) NOT IN

- **NOT IN is the opposite of IN**.
- It returns **TRUE only when the column value does *not* match any value** in the list.
- Used to **exclude** multiple values without writing many `AND` conditions.
- SYNTAX:

  ```sql
  SELECT COLUMN_NAME/EXP
  FROM TABLE_NAME
  WHERE COLUMN_NAME/EXP NOT IN (V1,V2,V3,V4,......Vn);			
  ```
- EXAMPLE:

  ```sql
  SELECT *
  FROM EMP
  WHERE DEPTNO NOT IN (10,20,30,40,);
  			---	WHERE DEPTNO NOT IN (~~10 OR 20~~ );  //NOT ALLOWED
  ```

## 3) BETWEEN

- It is used whenever we want to pass the values within the range
- we cannot interchange the range
- it works by including the given range (INCLUSIVE) LIKE ≤ AND ≥
- Syntax:

  ```sql
  SELECT COLUMN_NAME/EXP
  FROM TABLE_NAME
  WHERE COLUMN_NAME/EXP BETWEEN LOWER_RANGE AND HIGHER_RANGE;
  ```
- Examples:

  ```sql
  SELECT *
  FROM EMP
  WHERE SAL BETWEEN 1000 AND 5000; -- 1000 AND 5000 ARE INCLUDED.
  ```

  <aside>
    💡

  BRACKETS ARE NOT MANDATORY IF USING THE BETWEEN OPERATOR.

  BETWEEN(10,30) // IS NOT ALLOWED

  </aside>

## 5. IS

- **IS is a special comparison operator** used with NULL.
- **NULL** is a keyword that represents *unknown / missing* value.
- Since NULL cannot be compared using `=` or `!=`,
- **IS** is used to check if a value **is NULL** or **is NOT NULL**

<aside>
💡

Note:

`IS` operator is used only to check NULL values and cannot be used for normal value comparison.

</aside>

- Syntax:

  ```sql
  SELECT COLUMN_NAME/EXP
  FROM TABLE_NAME
  WHERE COLUMN_NAME/EXP IS NULL;
  ```
- Examples:

  ```sql
  SELECT ENAME
  FROM EMP
  WHERE COMM IS NULL OR COMM = 0;
  ```

  <aside>
    ❓

  ```sql

  ```

  </aside>

## 7) LIKE

- `LIKE` is used to perform pattern matching in a column using wildcard characters `%` and `_`.
- Syntax:

  ```sql
  SELECT COLUMN_NAME/EXP
  FROM TABLE_NAME
  WHERE COLUMN_NAME/EXP LIKE PATTERN_TO_MATCH;
  ```

### Wildcards used with `LIKE`

1. `%` (Percent)

   - It Represents zero or more characters
2. `_` (Underscore)

   - Represents any character but only one

   <aside>
    💡

   ## Oracle-specific note:


   - `LIKE` is **case-sensitive** in Oracle by default
   - Use `UPPER()` or `LOWER()` for case-insensitive search:

   ```sql
   WHERE UPPER(ENAME) LIKE 'A%';
   ```

   </aside>
