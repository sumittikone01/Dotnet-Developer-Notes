# Order By Clouse

It is used to sort records in Ascending or Descending order

1. Order by clause must be written as last clause in the statement.
2. It executed after the select clause.
3. By default it sort records in ascending order.
4. We can pass column name or expression as argument in order by clause.

- Syntax:

  ```sql
  SELECT GROUP_BY_EXPRESSION / GROUP_FUNCTION
  FROM TABLE_NAME
  [WHERE <FILTER_CONDITION>]
  [GROUP BY COLUMN_NAME/EXPRESSION]
  [HAVING <GROUP_FILTER_CONDITION>]
  ORDER BY COLUMN_NAME [ASC] / DESC;
  ```

<aside>
❓

WAQTD SALARY IN ASCENDING ORDER

```sql
SELECT SAL
FROM EMP
ORDER BY SAL ASC;
```

</aside>

<aside>
❓

WAQTD HIREDATE IN DESCEDING ORDER

```sql
SELECT HIREDATE
FROM EMP
ORDER BY HIREDATE DESC;
```

</aside>

<aside>
❓

WAQTD EMPLOYEE NAME IN AN ASCENDING ORDER

```sql
SELECT ENAME
FROM EMP

```

</aside>

IMPORTANT QUESTION

|         | HAVING              | WHERE                 |
| ------- | ------------------- | --------------------- |
| USED    | TO FILTER THE GROUP | TO FILTER THE RECORDS |
| EXECUTE | GROUP BY GROUP      | ROW BY ROW            |
|         | WE CAN USE MRP      | WE CANNOT USE MRF     |
