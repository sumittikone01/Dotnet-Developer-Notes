# SQL CLAUSES

***Those are keywords used to perform specific operations in a query.***

---

## **A) FROM Clause**

It Retrieve the table from the database & put table under execution.

### 🔹 What FROM does:

1. Goes to the database
2. Searches for the table
3. Loads the table into memory for execution

### Example:

```sql
SELECT ENAME 
FROM EMP;
```

---

## **B) SELECT Clause**

It display or return the specific columns from the table which is under execution.

### 🔹 What SELECT does:

1. Goes to the table already loaded by FROM
2. Selects the required columns
3. Displays the result

<aside>
💡

NOTE:

- If multiple columns with the same name exist after JOIN, SELECT will still fetch **all of them**, unless specified using alias.
- **FROM** clause starts the execution by locating the table in the database and putting it under execution.
- **SELECT** runs after FROM; it select the mentioned columns from the table and displays them.
- SELECT accepts , column names, or expressions.
- SELECT is responsible for the **final result table**.
- `*` or `TABLE_NAME.*`= select all columns.
- `;` = end of query.
- Table Name is not case sensitive
- Data in The Table is Case sensitive rest everything is not case sensitive.

</aside>

# **ORDER OF EXECUTION (VERY IMPORTANT)**

SQL does NOT execute queries in the order we write them.

### **Actual execution order:**

1️⃣ **FROM** → Pick the table

2️⃣ **WHERE** → Filter rows *(if present)*

3️⃣ **SELECT** → Pick columns to show

4️⃣ Other clauses (GROUP BY → HAVING → ORDER BY)
