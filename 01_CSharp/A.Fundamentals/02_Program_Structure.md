# 🏗️ Program Structure

## 📌 What is it?

> The basic skeleton of a C# program — the minimum pieces needed for code to compile and run, and how they're organized.

---

## 🧠 Intuition

Modern C# (Top-level statements, C# 9+) vs Classic structure:

```csharp
// ── Classic Structure ──
using System;

namespace MyApp
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello World");
        }
    }
}

// ── Modern (Top-level statements) ──
using System;

Console.WriteLine("Hello World");
```

Both compile to the same IL — top-level statements are just compiler sugar that auto-generates the `Program` class and `Main` method behind the scenes.

---

## ⚙️ Building Blocks

| Element             | Purpose                                                                      |
| ------------------- | ---------------------------------------------------------------------------- |
| `using` directive | Imports a namespace so you can use its types without full qualification      |
| `namespace`       | Logical container to organize/group related classes, avoid naming collisions |
| `class`           | Blueprint containing your code (fields, methods, etc.)                       |
| `Main` method     | Entry point — where program execution starts                                |
| `string[] args`   | Command-line arguments passed to the program                                 |

---

## 🖼 Execution Order

```
1. CLR loads assembly (.dll/.exe)
2. CLR looks for the Main() method entry point
3. Static constructors run (if any) — see 03_Constructors/04_Static_Constructor.md
4. Main() executes top to bottom
5. Program ends when Main() returns (or app is a long-running host like ASP.NET)
```

## 💻 Code Examples

**Basic — Classic style:**

```csharp
using System;

namespace HelloWorldApp
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello, World!");
        }
    }
}
```

**Intermediate — Using command-line args:**

```csharp
using System;

namespace HelloWorldApp
{
    class Program
    {
        static void Main(string[] args)
        {
            if (args.Length > 0)
                Console.WriteLine($"Hello, {args[0]}!");
            else
                Console.WriteLine("Hello, World!");
        }
    }
}
```

**Practical — Modern top-level statements (what you'll see in ASP.NET Core `Program.cs`):**

```csharp
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

app.MapGet("/", () => "Hello World!");

app.Run();
```

> 💡 This is exactly the pattern used in ASP.NET Core MVC's `Program.cs` — no visible `Main()`, but it's auto-generated by the compiler.

---

## 🚨 Common Mistakes

- ❌ Forgetting `Main` must be `static` — CLR calls it without creating an object first
- ❌ Multiple `Main` methods in one project without specifying the entry point → compiler error
- ❌ Mixing top-level statements with an explicit `Main` method in the same file → not allowed

---

## 🎤 Interview Questions

| Question                       | Key Point                                                                                      |
| ------------------------------ | ---------------------------------------------------------------------------------------------- |
| Why must`Main` be static?    | CLR invokes it before any object of the class exists                                           |
| Can`Main` return a value?    | Yes —`int Main()` — used to return exit codes to the OS                                    |
| What are top-level statements? | C# 9+ feature that removes boilerplate`class`/`Main` — compiler generates them implicitly |
